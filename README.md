# CAFETO — Sitio web para GitHub Pages

Archivos principales:
- `index.html` — página principal
- `menu.html` — menú digital con las imágenes originales
- `styles.css` — estilos responsive
- `script.js` — animaciones y navegación móvil
- `.nojekyll` — compatibilidad con GitHub Pages

## Publicar en GitHub Pages
1. Sube todos los archivos del ZIP a la raíz de un repositorio.
2. En GitHub abre **Settings > Pages**.
3. Selecciona **Deploy from a branch** y la rama `main`, carpeta `/root`.
4. Guarda y espera a que GitHub genere la URL.
